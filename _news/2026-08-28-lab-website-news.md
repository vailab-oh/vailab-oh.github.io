The source code for **TriV-Net+** is now publicly available.

TriV-Net+ is a multi-task learning framework designed for UAV-based visual perception, jointly addressing multiple perception tasks within a unified architecture. The released repository provides the implementation and supporting resources for reproducing and extending the proposed approach.

The code is shared to support reproducible research and further studies on multi-task perception for UAV and autonomous systems.
